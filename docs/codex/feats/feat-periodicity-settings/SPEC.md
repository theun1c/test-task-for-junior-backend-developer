# SPEC.md

## Название

Настройки периодичности задачи

## Цель

Добавить возможность задавать периодичность задачи и показывать её в календаре по этим настройкам без создания дублирующих записей в таблице задач.

## Описание

В системе есть обычные задачи.  
Нужно добавить поддержку периодических задач.

Пользователь должен иметь возможность указать календарные правила задачи:

- когда задача начинает действовать
- когда задача заканчивает действовать
- по какому правилу выбирать даты и время внутри этого интервала

Система не создаёт новые записи задач по расписанию. Вместо этого одна запись задачи хранит календарное правило, а приложение вычисляет, должна ли задача отображаться на выбранные дату и время.

## Поддерживаемые типы периодичности

- ежедневные — каждый `n`-й день
- ежемесячные — в указанные числа месяца (`1..30`)
- на конкретные даты и время
- по чётным или нечётным дням месяца

## Что должно поддерживаться в API

- создание задачи с настройками периодичности
- обновление настроек периодичности
- получение задачи вместе с настройками периодичности
- фильтрация задач по выбранным дате и времени календаря
- завершение конкретного календарного вхождения задачи

Формат даты и времени во входных данных API: `dd.mm.yyyy hh:mm`.

## Ожидаемое поведение

Система должна уметь определить, должна ли задача отображаться на конкретные дату и время, исходя из:

- интервала действия задачи
- настроек периодичности
- списка уже завершённых календарных вхождений

## Важное требование

Нельзя хранить дубли завершения одного и того же календарного вхождения задачи за одну и ту же дату и время.

## Готово, если

- настройки периодичности можно сохранить
- настройки периодичности можно изменить
- настройки периодичности возвращаются через API
- по выбранным дате и времени API возвращает задачи, которые попадают под календарное правило
- завершённое календарное вхождение больше не попадает в выборку
- дубли завершённых вхождений не создаются
