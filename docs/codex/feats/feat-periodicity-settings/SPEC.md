# SPEC.md

## Название

Настройки периодичности задачи

## Цель

Добавить возможность задавать периодичность задачи и создавать задачи по этим настройкам.

## Описание

В системе есть обычные задачи.  
Нужно добавить поддержку периодических задач.

Пользователь должен иметь возможность указать правила периодичности, по которым система будет создавать задачи автоматически.

## Поддерживаемые типы периодичности

- ежедневные — каждый `n`-й день
- ежемесячные — в указанные числа месяца (`1..30`)
- на конкретные даты
- по чётным или нечётным дням месяца

## Что должно поддерживаться в API

- создание задачи с настройками периодичности
- обновление настроек периодичности
- получение задачи вместе с настройками периодичности

## Ожидаемое поведение

Система должна уметь определить, нужно ли создать задачу на конкретную дату, исходя из её настроек периодичности.

## Важное требование

Нельзя создавать дубли одной и той же периодической задачи за одну и ту же дату.

## Готово, если

- настройки периодичности можно сохранить
- настройки периодичности можно изменить
- настройки периодичности возвращаются через API
- задачи создаются по заданным правилам
- дубли не создаются
