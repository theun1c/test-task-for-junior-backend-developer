# CONTEXT.md

## О проекте

Проект представляет собой API модуля трекера задач в составе медицинской информационной системы.

## Назначение

Модуль нужен для работы с задачами персонала.
Через него пользователи могут создавать, изменять, удалять и просматривать задачи.

## Примеры задач

- провести операцию
- связаться с клиентом
- сделать обход пациентов
- подготовить отчетность
- выполнить внутренние рабочие действия

## Что важно понимать

Это не новый проект, а уже существующий код.
Основная работа ведётся через доработку текущей реализации, а не через создание архитектуры с нуля.

## Технический контекст

- Язык: Go
- Проект уже содержит API для работы с задачами
- В проекте уже есть базовые CRUD-операции для задач

## Общие ожидания от доработок

- сохранять совместимость с существующим поведением
- не ломать текущие сценарии
- встраиваться в текущую структуру проекта
- делать изменения минимально необходимыми

## Перед началом любой новой фичи нужно изучить

- структуру сущности задачи
- DTO / request / response модели
- handlers
- сервисный слой
- слой работы с БД
- существующие тесты
- фоновые процессы или scheduler, если они есть

## Общий принцип работы

Сначала понять, как проект устроен сейчас.
Потом определить минимальную точку расширения.
После этого вносить изменения без лишнего усложнения.
