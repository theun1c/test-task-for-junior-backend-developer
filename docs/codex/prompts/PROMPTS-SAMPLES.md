# Базовый промпт на старт

Изучи файлы проекта и работай строго от них:

- AGENT.md
- docs/codex/project/CONTEXT.md
- docs/codex/feat-name/SPEC.md
- docs/codex/feat-name/TASKS.md
- README.md

Сначала прочитай их и кратко зафиксируй:

1. что это за проект
2. какая цель текущей фичи
3. какие ограничения и правила работы нужно соблюдать
4. какой следующий лучший шаг

После этого действуй только в рамках текущей задачи.
Не придумывай лишнюю архитектуру.
Не делай лишний рефакторинг.
Следуй существующей структуре проекта.
Если есть неоднозначность — выбери минимальный рабочий вариант и явно укажи это.

Формат ответа:

1. Контекст
2. План
3. Реализация / анализ
4. Риски или вопросы
